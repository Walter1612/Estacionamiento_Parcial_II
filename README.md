# Examen Parcial II — Estacionamiento

## Contenidos aplicados

- Programación orientada a objetos y encapsulamiento.
- Clase abstracta `Vehiculo`.
- Herencia con `Motocicleta`, `Automovil` y `VehiculoPesado`.
- Sobrescritura de métodos.
- Polimorfismo para calcular el costo.
- Colección genérica `LinkedList<RegistroEstacionamiento>`.
- Ciclos `for`, condicionales y `switch` tradicional.
- Validaciones de datos.
- `try-catch`, `NumberFormatException` y excepciones personalizadas.
- PostgreSQL, JDBC y SQL básico.
- Operaciones `INSERT`, `SELECT` y `UPDATE` desde Java.
- Ejemplos SQL de `DELETE`, filtros y ordenamiento.

## Tarifas utilizadas

- Motocicleta: Q5.00 por hora.
- Automóvil: Q8.00 por hora.
- Vehículo pesado: Q12.00 por hora.
- Se cobra un mínimo de una hora.

## Ejecutar en IntelliJ

1. Abra la carpeta `estacionamiento-parcial-II`.
2. Confíe en el proyecto y permita que Maven cargue la dependencia de PostgreSQL.
3. Abra `src/main/java/gt/edu/parqueo/Main.java`.
4. Ejecute `Main.main()`.
